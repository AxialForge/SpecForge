    SpecForge

    Forge a spec sheet from any PC.

    Version · Electron · Chromium

    SpecForge reads a Windows PC's hardware and software, shows it in one place, and exports it as CSV, JSON or plain text — ready to paste into an AI assistant for an instant marketplace listing, or to keep as an audit record. Everything stays on this machine; nothing is uploaded.

    Made by AxialForge · MIT licence · Built with Electron and systeminformation.
    Data folder:

    Include private data in exports?

    Exports will then contain serial numbers, the Windows product key, MAC and IP addresses, and your computer and user names. Anyone who receives the file can read them. Only use this for your own audit records — never for a listing you post online.
